# Semagn Legese Mildega — Next.js Portfolio

A modern, high-performance developer portfolio built with **Next.js 15 (App Router)** and styled according to the **Impeccable Craft Floor** & **UI/UX Pro Max** design guidelines.

## 🚀 Key Features

- **App Router Architecture:** Modern Next.js (`app/layout.jsx`, `app/page.jsx`, `app/cv/page.jsx`).
- **Zero-Layout-Shift Fonts:** Optimized loading with `next/font/google` (`Plus Jakarta Sans`, `Inter`, `JetBrains Mono`).
- **Interactive Live Preview Modal:** Test all 5 live projects in an embedded responsive preview frame right on the portfolio without navigating away.
- **Projects Filter Bar:** Filter by *All*, *Full-Stack Apps*, *Real-Time & Geo*, or *Enterprise & University*.
- **Themed Browser Surfaces:** Custom scrollbars, styled `::selection`, `caret-color`, and WCAG AA `:focus-visible` outlines.
- **Micro-Interactions:** One-click copy email pill with toast notification, persistent dark/light theme switch, reading progress bar.
- **Dedicated Curriculum Vitae Page:** Accessible at `/cv` with print optimization (`window.print()`).

## 🛠️ Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) to view the site.
